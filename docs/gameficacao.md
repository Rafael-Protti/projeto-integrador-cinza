# Introdução
Essa é uma página de gamificação de um site de troca de itens colecionáveis.
Esse é um projeto que usa a tecnologia **ReactJS**.

## Instruções
1. Leia os arquivos `Gameficacao.jsx` e `Gameficacao.css` para se contextualizar do que foi feito;

2. Leia a tag `section` com a classe **painel-missoes** e encontre dentro a `div` com a classe `lista-missoes`;

4. Encontre os botões com as classes **aba ativa** e **aba**;

3. Altere o html, javascrip e css para que esses botões de missões *diárias* e *semanais* fiquem funcionais, mudando as missões exibidas na lista;

5. Altere apenas os arquivos listados acima.
