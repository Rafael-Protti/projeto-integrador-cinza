# Cadastro
 - A página principal é de cadastro, uma froma que os cliente vão se cadastrar em descrições pedidas como: Nome completo, Email, Telefone e quantas vezes poderá ser trocado os itens dessa loja. - Na principal página vai conter uma barra de pesquisa, em busca dos produtos que vendemos em nossa loja. 

# Descrição 
- Dentro desses requisitos que foram dispostos em cima, precisa ter um cabeçalho,título, painel de perfil do usúario e precisa conter um enquadramento para colocar a foto do cliente. E os cards de coleção para o cliente vizualizar os produtos,e um rodapé no final. 

# Instruções
- campos de texto: validar o nome para aceitar apenas letras e sobrenome.
- Máscara de telefone:  Aplicar formatação autómatica enquanto digita (ex:(11) 99999-9999) 
- Validação de email: Bloquear envios se o formato não contiver @ ou um domínio válido.
- Edição do perfil: Criar um botão "Salvar alterações" que só aparece quando um dado for modificado.
- Upload de imagem: configurar o botão "Trocar foto" para abrir os arquivos do dispositivo.
- Limitação de arquivo: Restringir o upload para formatos específicos (-jpg, -png ) e tamanho máximo (ex: até 2MB).
- Corte de imagem: Adicionar uma ferramenta visual para o usuário centralizar ou cortar foto em formato circular. 
-  Atualização automática: Vincular o "Número de Trocas" ao banco de dados para subir +1 ponto a cada transação finalizada.
- Contador de itens: Atualizar dinamicamente a quantidade de itens em cada categoria (ex: "18 itens") sempre que o usuário adicionar ou remover algo da coleção.
-  Barra de pesquisa: Configurar para buscar por itens específicos dentro do perfil do usuário ou em todo o site.
-  Botões vazios: Definir funções para os três retângulos escuros no topo (ex: "Início","Mensagens", "Configurações").
-  Interação com coleções: Programar os botões "Ver coleção" para redirecionar o site para não subir +1 ponto a cada transação finalizada.
