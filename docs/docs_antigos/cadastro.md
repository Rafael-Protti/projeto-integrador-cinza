## Instruções para criação
*Adicionar instruções que estão além da estruturação do site, por exemplo: qual o nome dos arquivos criados? quais arquivos vão ser editados? onde esses arquivos serão criados? quais arquivos vão ser lidos para contexto ou referencia? etc*
- *Usar tópicos para facilitar visuaização* 
*Adicionar instruções gerais importantes se necessário. Exemplo: Todos os componentes do site devem aparecer na página, sem arrastar a tela para baixo.*

*Em seguida, crie subtítulos (###) para as `Instruções` para cada estrutura da página. Dentro desses campos que você criar, seja o mais epecífico em como você quer o site. Exemplo: Não diga para a IA apenas comprar pão na padaria. Que caminho ela deve percorrer para chegar na padaria? Qual padaria ela precisa entrar? Que pão ela vai comprar? Quanto vai comprar? Como vai pagar?*
*Se você não especificar, a IA vai fazer como ela achar que é o melhor modo, mas o modo que ela escolher, pode não ser o que você quer. Especifique: Pegue a rua tal, vire na rua tal, entre na padaria X, compre tantos pães do tipo tal, pague com tanto dinheiro, volte para casa e etc. Deixe seus comandos "a prova de falha"*
*Mas não precisa ser super específico, exemplo: o título vai ter 13.45 pixels de largura, dentro de uma caixa de 44.78 pixels de altura, com padding: de 3.2121312 pixel etc etc*
