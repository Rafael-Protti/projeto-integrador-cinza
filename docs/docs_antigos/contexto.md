 # Reformulação do site 
- Dentro do site precisa conter uma organização de estrutura e análise de observação analítica. 
 uma das principais referências que tenho é uma venda de artigo envolvidos por troca e limite de produtos dentro da plataforma.

 # Análise
 - A estruturação desse sistema é de tonalidade azul como expiração do site e app da Magazine Luiza. Mas a simples conclusão deve ser feita é sobre os requisitos de proporção e layout do site em função de ser um "site Vitrine".
 - A estrutura inicial da página cadastral tem notificação,mensagens e login/cadastral 
 - Uma estruração da navbar, e logo em seguida menu de informações e uma estruturação de reiniciação. 


 # Conteúdo 
 - O conteúdo é diversificado, por diversos produtos em categorias diferentes.
 - Cards de proposta 

 # Regras de négocio 
 - O usuário terá que preencher um formulário, para que o site possa analisar os dados e ter acesso de visualizar os produtos.
 - O usuário tem um limite de produtos, que não pode ser ultrapassado. O limite é de 10 produtos.

 # Observação 
 - O site é simplesmente uma vitrine de produtos, não tem carrinho de compras nem pagamentos. É só um site para expor os produtos.
 - Em baixo dos cards de proposta do produto, tem um botão de ver coleção. Esse botão deve levar para uma página com os detalhes do produto. 

 # Coleção 
 - Estara englobado pelas categorias de produtos e cards de coleção. Portanto a estrutura desse conteúdo é a imagem ficar dentro do card e ser alinhado lateralmente com o título e número de itens, e por fim o botão. 

 # Itens 
 - Cartinha: 23 unidades
 - Disco de Vinil: 12 unidades 
 - livro: 18 unidades 
 - Jogo: 4 unidades 

 # Regras de negócio 
 - O site deve permitir o cadastro e login de usúarios. O cadastro deve solicitar nome, email, senha e telefone. O login deve permitir o acesso ao perfil do usúario. O perfil deve conter uma foto do usúario, nome, email, telefone e uma lista de produtos que o usúario deseja trocar.
