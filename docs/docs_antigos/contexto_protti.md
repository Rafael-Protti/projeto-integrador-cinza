# Site de Troca de itens colecionáveis
Esse é um site onde as pessoas se encontram para publicar seus itens colecionáveis e trocar entre si.

Será utilizado **apenas** HTML5 e CSS3 para o seu desenvolvimento, **sem nenhuma outra tecnologia**, a princípio (Exemplo : JavaScript). 

Nele será possível criar seu perfil, publicar seus itens, buscar itens de outros usuários e realizar trocas.

Todas as trocas são feitas **externamente** ao site e são responsabilidade dos usuários. Aqui será apenas divulgado o item e o contato do negociante.

O site aceita qualquer item colecionável, referente à cultura pop, por exemplo: action figures, cards, bonecos, chaveiros, entre outros.

## Instruções para a criação
- Não criar arquivos se não for pedido.
- Não modificar arquivos existentes sem permissão.
- Ao criar uma página, o arquivo CSS deve ter o mesmo nome do arquivo HTML.
- Todos os arquivos HTML e CSS são criados na **pasta raiz**.
- Todas as imagens das páginas são armazenadas na pasta `imagens`.
- Os arquivos de contexto e de instruções são armazenados na pasta `Docs`.
