# Introdução
Este é um site para troca de produtos colecionáveis.
Os usuários exibem seus itens em postagens e os usuários podem entrar em contato com o anunciante para fazer a negociação.


## Carrinho

```
create table public.carrinho (
  id bigint generated by default as identity not null,
  created_at timestamp with time zone not null default now(),
  id_usuario bigint not null,
  id_produto bigint not null,
  status boolean null,
  constraint carrinho_pkey primary key (id),
  constraint carrinho_id_produto_fkey foreign KEY (id_produto) references produtos (id) on update CASCADE on delete CASCADE,
  constraint carrinho_id_usuario_fkey foreign KEY (id_usuario) references usuarios (id) on update CASCADE on delete CASCADE
) TABLESPACE pg_default;
```

## Coleção

```
create table public.colecao (
  id bigint generated by default as identity not null,
  id_usuario bigint not null,
  nome character varying not null,
  categoria character varying null,
  qtd_item integer null,
  imagem text null,
  created_at timestamp with time zone not null default now(),
  constraint colecao_pkey primary key (id),
  constraint colecao_id_usuario_fkey foreign KEY (id_usuario) references usuarios (id) on update CASCADE on delete CASCADE
) TABLESPACE pg_default;
```

## Produtos
